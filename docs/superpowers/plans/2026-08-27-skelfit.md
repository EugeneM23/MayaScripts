# maya_skelfit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A root-level tool that builds a UE5 Manny-schema skeleton fitted to
a humanoid mesh and voxel-binds the mesh, plus the `manny-skeleton` skill
that drives it interactively over the bridge.

**Architecture:** One flat file `maya_skelfit.py` in the repo root (the
standalone-tool convention): pure sections (template, fit math, orientation
solver — data in, data out) and a thin scene side (`build`, `finalize`,
`bind`, `pose_test`, `screenshot`). Template data is the committed
`assets/manny_skeleton_template.json` (spec: measured facts).

**Tech Stack:** maya.cmds, maya.api.OpenMaya (math types only in pure code),
stdlib json. Tests: mayapy + unittest (`& 'C:\Program Files\Autodesk\
Maya2027\bin\mayapy.exe' -m unittest discover -s tests -t . -v`).

## Global Constraints

- Skeleton must reproduce the template exactly: names, hierarchy,
  `rotateOrder` xyz, `segmentScaleCompensate` off, `jointOrient` zero
  everywhere but `root`, bind orientation in ROTATE channels.
- `root` keeps its template channels verbatim and never moves.
- Bind influences = the template's `weighted_influences` of the body mesh
  (74 joints), `maxInfluences` 8, geodesic voxel.
- Refusals, not guesses: existing joints in scene, no/ambiguous target
  mesh, mesh already skinned.
- Never key or write literal rest values in the live scene; autoKey off
  around pokes, exact restore (trap 14 / trap 30).
- Spec: `docs/superpowers/specs/2026-08-27-skeleton-skin-skill-design.md`.
