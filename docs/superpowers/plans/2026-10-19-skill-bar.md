# Skill bar - build order (2026-10-19)

Spec: `docs/superpowers/specs/2026-10-19-skill-bar-design.md`.

1. `maya_skillbar/look.py` + tests: model, JSON, defaults, geometry, hits, labels, captions.
2. `maya_skillbar/store.py` + tests: the file, defaults, a broken file kept aside, atomic write.
3. `maya_skillbar/run.py` + tests on fake modules: every kind runs; labels; the Script Editor text.
4. `maya_skillbar/sources.py` + tests on fake modules: the drawer's entries.
5. `maya_skillbar/grid.py`: page row + cells (paint, hover, click, menus, drag, drops, text drop).
6. `maya_timebar/bar.py`: the page row and the grid in the Strip, the time box, `show_page`, the
   burst over the new parts; `maya_timebar/scene.py` forwarding; the docked height.
7. `maya_skillbar/library.py`: the drawer.
8. `maya_skillbar/__init__.py`: `page(n)` (edge reveal, Maya's slider message), `aim` / `drop` /
   `light`; hotkey rows `skills.page1..12`, F1-F12 in `DEFAULT_KEYS` (version 8).
9. Drags from our panels: portraits, Pose Library cards, weapon tiles, rail icons.
10. Payload row, CLAUDE.md, the filmstrip, the whole unit suite.
