# Hub skin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The SkeldarAnim hub in style B: header (hotkeys, version, menu), a jump strip, grouped rounded cards, one orange primary button per section, the buttons rearranged — every cmds control, name and callback kept.

**Architecture:** A Qt skeleton of ours (root → header → strip → scroll → group labels → cards) inside the same `workspaceControl`; each card body is a named Qt layout the tool's `build_panel()` runs into through `cmds.setParent(MQtUtil.fullName(...))`. Builders mark controls with roles (`maya_hubstyle.mark`); after each builder the Qt layer turns marks into `skRole` properties, icons, swatches and moved subtitles; one stylesheet on the root styles it all. Without Qt, or when asked, the classic frameLayout accordion is built.

**Tech Stack:** Maya 2027 `maya.cmds`, PySide6 6.8.3 (PySide2 fallback), QtSvg, stdlib `unittest` under mayapy (`QT_QPA_PLATFORM=offscreen`).

Spec: `docs/superpowers/specs/2026-09-28-hub-skin-design.md`

## Global Constraints

- Run tests: `& 'C:\Program Files\Autodesk\Maya2027\bin\mayapy.exe' -m unittest discover -s tests -t .` from the repo root, `$env:QT_QPA_PLATFORM='offscreen'`. Never `python`.
- `maya_hubstyle.py`, `maya_hubicons.py`: stdlib only (a subprocess test pins it).
- `maya_hubqt.py`: the only new module importing Qt; `maya_hub.py` imports it lazily.
- Stylesheet px and icon sizes × `cmds.mayaDpiSetting(query=True, realScaleValue=True)`.
- Class-specific Qt calls on Maya controls go through `setProperty` (`wordWrap`, `icon`, `iconSize`), never wrapper methods (wrapper cache, spec fact 6).
- No blanket descendant background rules; no `QLabel` background rule (spec fact 3).
- Every Qt object of ours gets an `objectName` (they are parts of cmds paths).
- A rebuild triggered from inside the hub is `evalDeferred(lowestPriority=True)`.
- Control names every tool already uses stay; the tests of old behaviour change only where the layout deliberately changed.
- Commit after each task; messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
