SkeldarAnim — набор инструментов аниматора для Maya:
UE Bridge, Scene Setup, Retarget, Bake, Overshoot, Hotkeys, Studio,
Colour, Curves.

Требуется Maya 2025 или новее: Curves (Curve Overlay) построен на PySide6,
который появился в Maya начиная с 2025-й. Остальные кнопки работают и на
более старых версиях.

Установка:
  1. Распакуйте папку куда угодно.
  2. Перетащите файл install.py в открытое окно Maya (во вьюпорт).
  3. Появится полка SkeldarAnim с девятью кнопками.
     После этого распакованную папку можно удалить.

Рабочий цикл:
  Scene Setup > Add Character  — риг AdvancedSkeleton (Manny [rig]) в сцену;
                                 чистые скелеты UE5/UE4 — в том же списке.
  UE Bridge > IMPORT           — анимация из открытого редактора Unreal:
                                 риг добавляется сам, если его нет, клип
                                 ретаргетится и запекается на риг, исходный
                                 скелет удаляется. Режим «as a new skeleton»
                                 импортирует только скелет с анимацией.
  Retarget / Bake              — то же вручную: выделите импортированный
                                 скелет, Retarget — риг следует за ним,
                                 Bake — запекание, перенос weapon/camera
                                 костей, камера, отключение.
  Scene Setup > Add            — оружие в руку персонажа (выделите любой
                                 его контрол или кость).

Кнопка Hotkeys включает временную карту горячих клавиш: Maya
  переключается на набор SkeldarAnim, кнопка подсвечивается, повторное
  нажатие возвращает ваш обычный набор. При первом нажатии набор
  создаётся копией текущего (все ваши клавиши остаются на месте) и
  открывается штатный редактор — Windows > Settings/Preferences >
  Hotkey Editor. Команды наших инструментов лежат там в категории
  SkeldarAnim; выбирайте и вешайте на клавиши.

Обновление: перетащите install.py из новой версии ещё раз.
  Если какая-то из наших панелей была открыта — закройте её и откройте
  заново с полки. Если и после этого открывается старая версия,
  перезапустите Maya.

  И удалите распакованные папки от прежних версий: если такая папка
  осталась в sys.path, Maya может грузить инструменты из неё, а не из
  установленной копии.

Удаление: удалите вкладку полки SkeldarAnim (ПКМ по вкладке) и папку
  Документы/maya/scripts/SkeldarAnim
