/*Set of basic scripts for the OverRig animation method
Author: Pavel Barnev pavel_barnev2000@mail.ru
Installation:
Quick Installation:
    unzip the file into a directory of choice
    Start Maya.
    Drag file:
	Drag_and_Drop_to_install.mel
	into a MAYA window. The script icon will appear on current tab on the Shelf Editor
What is OverRig animation method??
	- convert the animation of objects into a convenient structure for animating this episode
it is a powerful animation technique
	-  will speed up the animation creation process by simplifying your animation rig
	- fixes bugs in animation
	- an easy way to do what the rig doesn't allow
	- if the Rig is missing something,  add it without losing the animation
	- animate secondary motion,  physical detail and overlapping action.
	- Animate tails, wings, or any chain of bones
	- improve finished animations
	- change the Rig hierarchy as you want
	- polish hand-made animations and MoCap
	- interaction with objects and environment
	- interaction with another character
	- and many many others
Best way to use tool:
	1.	sketch out the animation.
	2.	the main thing is to get an overall good sketch of the movement.
	3.	Ignore the inaccuracies of animations
	4.	after that - use these tools to bring the animation to perfection
